# L-LAN

ระบบที่ 2 สำหรับงานภาษีที่ดินและสิ่งปลูกสร้าง ใช้เตรียมข้อมูล แก้ไข และตรวจสอบในเครื่องก่อน แล้วจึงส่งเข้า LTAX ONLINE
เป็นเว็บแอปที่ทำงานในเครื่อง ข้อมูลอยู่ในโฟลเดอร์ `data` ไม่มีการส่งออกไปที่อื่น นอกจากตอนสั่งงานกับ LTAX

## เปิดใช้งาน

ต้องมี Node.js 22 ขึ้นไป และ Google Chrome หรือ Microsoft Edge โปรแกรมนี้ไม่ต้องติดตั้งแพ็กเกจเพิ่ม

- ดับเบิลคลิก `เปิด L-LAN.cmd` หรือเปิด terminal ในโฟลเดอร์นี้แล้วพิมพ์ `node server.mjs`
- เปิด http://127.0.0.1:4380

ค่าที่ปรับได้ผ่าน environment variable:
- `LLAN_DATA_DIR`: โฟลเดอร์ข้อมูล ค่าเริ่มต้นคือ `./data`
- `LLAN_PORT`: พอร์ต ค่าเริ่มต้นคือ 4380
- `LLAN_HOST`: ค่าเริ่มต้นคือ 127.0.0.1 จึงเปิดได้เฉพาะเครื่องนี้

## ขั้นตอนทำงาน

1. **นำเข้าข้อมูล** ที่แท็บ "นำเข้า / ส่งออก"
   - Excel ที่ส่งออกจาก LTAX ต้องมีชีต owner, land, land_detail, building, building_detail และ sign
   - ไฟล์แผนที่ .shp ของแปลงที่ดินและสิ่งปลูกสร้าง เลือก .shp .dbf .shx .prj .cpg พร้อมกัน
   - ระบบพิกัดที่รองรับ: WGS84, UTM 47N/48N และ Indian 1975 UTM 47N/48N โดยใช้ค่าแปลงพิกัด 210, 814, 289 เหมือนรายงานใน QGIS
   - ระบบจอยแผนที่กับทะเบียนด้วยรหัสแปลง (`parcel_cod`) และรหัสสิ่งปลูกสร้าง (`building_c`) ทันที
   - ข้อความไทยที่ถูกแปลงรหัสซ้ำสองชั้นจนอ่านไม่ออก (เช่น "เธช.เธ.เธ.4-01") จะถูกซ่อมเป็นภาษาไทยปกติ (ส.ป.ก.4-01) ตอนนำเข้า ซ่อมเฉพาะเมื่อแปลงกลับแล้วได้ภาษาไทยที่ถูกต้อง ข้อความไทยปกติจะไม่ถูกแตะ
2. **ดูแผนที่** ที่แท็บ "แผนที่"
   - คลิกแปลงหรืออาคารเพื่อดูข้อมูลที่นำเข้า
   - ระบายสีได้ 5 แบบ: ตามการจอย, รายการรอส่ง, ผลตรวจ, การใช้ประโยชน์, อาคารตรงแปลง
   - พื้นหลังเลือกได้ระหว่าง OSM และภาพดาวเทียม ซึ่งต้องใช้อินเทอร์เน็ต
   - แก้รหัสและข้อมูลของรูปแปลงได้จากแผงด้านขวา
   - **เครื่องมือวาดและแก้ไขรูป** (แถบด้านขวาของแผนที่):
     - วาดแปลง: คลิกทีละมุม แล้วจบด้วยการดับเบิลคลิก กด "เสร็จ" หรือคลิกจุดแรก
     - อาคาร 3 จุด: คลิก 2 มุมของด้านหนึ่ง แล้วคลิกด้านตรงข้าม
     - อาคารอิสระ: วาดอาคารแบบหลายเหลี่ยม
     - แก้ไขรูป: ลากจุดเพื่อย้าย แตะจุดเล็กกลางเส้นเพื่อเพิ่มจุด แตะจุดแล้วกด "ลบจุด" เพื่อลบ และย้อนได้ (Ctrl+Z)
     - Snap: ดูดติดจุดและเส้นของรูปข้างเคียง
     - GPS: แสดงตำแหน่งปัจจุบันพร้อมวงความคลาดเคลื่อน และเพิ่มจุดจาก GPS ระหว่างวาดได้
   - ทุกการบันทึกหรือลบรูปมีป๊อปอัพยืนยัน และแสดงพื้นที่ก่อนและหลังแก้
   - **ข้อมูลเบื้องต้นตอนวาดรูปใหม่:**
     - แปลงใหม่: ได้เนื้อที่ ไร่-งาน-วา จากรูป หมู่/ตำบลจากแปลงข้างเคียง และรหัสแปลงถัดไปที่แนะนำ หรือเลือกจากที่ดินในทะเบียนที่ยังไม่มีรูปเพื่อผูกรูปกับข้อมูลเดิม
     - อาคารใหม่: ได้แปลงที่ตั้ง เจ้าของ หมู่ รหัส B00x ถัดไป และขนาดกว้าง×ยาวจากรูป
   - **ภาพดาวเทียม:** เส้นแปลงเปลี่ยนเป็นเส้นสว่างมีขอบเข้มอัตโนมัติ ภาพ Esri มีถึงระดับซูม 18 ถ้าซูมใกล้กว่านั้นจะขยายภาพระดับ 18
3. **แก้ไขทะเบียน** ที่แท็บ "ทะเบียน" หรือปุ่มบนแผนที่
   - หน้าแก้ไขที่ดินแสดงสิ่งปลูกสร้างและป้ายในแปลง เปิดดูได้ และเพิ่มสิ่งปลูกสร้างในแปลงได้
   - ก่อนบันทึกจะสรุปช่องที่เปลี่ยนให้ยืนยัน และถ้าปิดฟอร์มทั้งที่ยังไม่บันทึกจะถามก่อนเสมอ
   - ฟอร์มมีช่องเดียวกับ LTAX ทุกช่อง
   - ช่องสีเหลืองคือช่องที่ต่างจากค่าใน LTAX ชี้ที่ช่องเพื่อดูค่าเดิม
   - **ราคาประเมิน:**
     - ที่ดินใช้ราคาต่อ ตร.ว. ส่วนสิ่งปลูกสร้างใช้ราคาต่อ ตร.ม.
     - ระบบคำนวณราคารวม ทุนทรัพย์ ค่าเสื่อม และคงเหลือให้
     - แสดงตัวเลขที่ LTAX คำนวณไว้ในไฟล์ส่งออกคู่กัน คือราคารวม ภาษีแยกตามการใช้ประโยชน์ และค่าเสื่อมของอาคาร
     - ถ้ายังไม่มีราคา จะมีปุ่ม "ใช้ราคาแนะนำ"
   - **ทำงานหลายรายการพร้อมกันในแท็บทะเบียน:** ติ๊กเลือกรายการ (หรือ "เลือกทั้งหมดที่กรองไว้") แล้วเลือกคำสั่ง ได้แก่
     - ตรวจข้อมูล
     - ตรวจว่ามีใน LTAX
     - ทดลองกรอก / บันทึกเข้า LTAX
     - ดึงจาก LTAX
     - เติมราคาประเมิน
     - ดูบนแผนที่
     - ลบ
   - **ลบเจ้าของ:** แสดงที่ดิน สิ่งปลูกสร้าง และป้ายที่เกี่ยวข้องก่อนลบ เลือกได้ว่าจะลบเฉพาะเจ้าของ หรือลบพร้อมทรัพย์สินที่เป็นเจ้าของคนเดียว
     - การลบเกิดใน L-LAN เท่านั้น
     - รายการที่มีใน LTAX จะไปอยู่ใน "รอลบใน LTAX" ที่หน้าสรุปการแก้ไข เพื่อไปลบในระบบเอง
4. **ตรวจสอบ** ที่แท็บ "ตรวจสอบ"
   - "ผิดพลาด" = ห้ามส่งเข้า LTAX
   - "เตือน" = ควรดู แต่ส่งได้
   - ปัญหาในช่องที่ยังเป็นค่าเดิมจาก LTAX นับเป็นเตือน เพราะระบบไม่แก้ช่องที่ไม่ได้เปลี่ยน
5. **สรุปการแก้ไข** แสดงทุกรายการที่ต่างจาก LTAX เป็นค่าเดิม → ค่าใหม่ และมีประวัติการแก้ไขทั้งหมด
6. **ส่งเข้า LTAX**
   - เปิดหน้าต่างเข้าสู่ระบบ แล้วเข้า DLA SSO ด้วยชื่อผู้ใช้ รหัสผ่าน และ OTP ด้วยตัวเอง L-LAN ไม่เก็บรหัสผ่าน
   - **ทดลอง:** เปิดฟอร์มใน LTAX กรอกค่า อ่านกลับมาเทียบ แล้วออกโดยไม่บันทึก
   - **บันทึกจริง:** ต้องเปิดในหน้าตั้งค่าก่อน ระบบจะกดบันทึก ตอบคำถามยืนยันปีภาษี แล้วค้นหาและอ่านค่ากลับมาตรวจทุกรายการ
   - **ดึงข้อมูล:** อ่านค่าปัจจุบันจาก LTAX มาเก็บในเครื่อง
   - ทุกงานแสดงความคืบหน้าทีละรายการ และดาวน์โหลดรายงาน Excel ได้
   - **ทำเป็นรอบ:**
     - กำหนด "เริ่มที่ลำดับ" และ "จำนวนต่อรอบ" ได้ กดเริ่มงานซ้ำเพื่อทำรอบถัดไป ระบบจำลำดับที่ทำถึงไว้ให้
     - "↻ ทำต่อรายการที่ค้าง/ผิดพลาด" ทำเฉพาะรายการที่ยังไม่สำเร็จของงานเดิม
   - **ส่งจากแผนที่:** ใช้เครื่องมือ "เลือกหลายแปลง" แตะรูปแปลงหรือกด "เลือกทุกแปลงในกรอบจอ" แล้วสั่งตรวจหรือส่งเข้า LTAX จากแผงด้านขวา
   - **โหมดสี "สถานะบันทึกเข้า LTAX"** มี 6 สถานะ:
     - บันทึกเข้า LTAX แล้ว
     - ทดลองผ่าน
     - ผิดพลาดครั้งล่าสุด
     - ยังไม่มีใน LTAX
     - แก้ไขแล้วรอส่ง
     - ตรงกับ LTAX
7. **ส่งออก**
   - Excel: ใช้หัวคอลัมน์เดียวกับไฟล์ที่ส่งออกจาก LTAX จึงนำกลับเข้ามาได้ พร้อมชีตผลตรวจ รายการรอส่ง และรายงานการจอย/ซ้อนทับ
   - .shp: ใช้ระบบพิกัดเดิมของชั้น และเพิ่มช่องข้อมูลทะเบียนที่จอยแล้ว

## Supabase: ข้อมูลกลางที่หน้าเว็บและเครื่องสำนักงานใช้ร่วมกัน

**แบ่งหน้าที่:**
- **Supabase เก็บข้อมูลกลาง:** ทะเบียน (เจ้าของ รวมชื่อ เลขบัตร ที่อยู่, ที่ดิน, สิ่งปลูกสร้าง, ป้าย, รายการรอลบใน LTAX) และรูปแปลง/รูปอาคาร
  - เฉพาะอีเมลที่อยู่ใน `llan_members` อ่านได้ (RLS) คนที่ล็อกอินได้แต่ไม่อยู่ในรายชื่อจะไม่เห็นข้อมูลใด ๆ
  - ไฟล์ .shp ที่นำเข้าส่งขึ้นครบทุกช่อง (สร้างแผนที่และข้อมูลใน Supabase ให้ระบบสำรวจใช้)
- **หน้าเว็บ (github.io):** ดู แก้ เพิ่ม ลบ ข้อมูลสำรวจได้จากทุกที่ ไม่ต้องเปิดเครื่องสำนักงาน
- **เครื่องสำนักงาน (L-LAN ในเครื่อง):** ที่เดียวที่ล็อกอิน LTAX (DLA SSO + OTP) และส่งข้อมูลเข้า LTAX
  - ส่งการแก้ไขในเครื่องขึ้น Supabase ภายในไม่กี่วินาที (ถ้าเน็ตหลุดจะเก็บคิวไว้ส่งทีหลัง)
  - ดึงการแก้ไขจากเว็บทุก 1 นาที และดึงอีกครั้งก่อนเริ่มงาน LTAX ทุกครั้ง
  - การแก้ไขบันทึกทีละช่อง: คนละคนแก้คนละช่องของรายการเดียวกัน ค่าของทั้งสองคนอยู่ครบ ถ้าแก้ช่องเดียวกัน ค่าที่บันทึกทีหลังจะเป็นค่าสุดท้าย
  - ประวัติการแก้ไข (ใคร แก้อะไร ก่อน/หลัง) อยู่ในตาราง `llan_change_log`

**ตั้งค่าครั้งแรก:**
1. **สร้างตาราง:** L-LAN → ตั้งค่า → "คัดลอก SQL สร้างตาราง" → Supabase → SQL Editor → New query → วาง แล้วกด Run
   - เป็นไฟล์ `supabase/schema.sql` + `supabase/web-access.sql` + `supabase/records.sql` รวมกัน รันซ้ำได้
2. **เพิ่มผู้ใช้:** Supabase → Authentication → Users → Add user (ใส่อีเมลและรหัสผ่าน ติ๊ก Auto Confirm)
   แล้วรันใน SQL Editor: `insert into public.llan_members (email, role) values ('อีเมล', 'admin') on conflict (email) do update set role = excluded.role;`
   - role: viewer (ดูอย่างเดียว), editor (แก้ไขได้), admin (ผู้ดูแล)
   - ควรปิด "Allow new users to sign up" ใน Authentication → Sign In / Providers
3. **ใส่ key:** L-LAN → ตั้งค่า → Supabase → ใส่ Project URL และ secret key จาก Supabase → Project Settings → API Keys
   - key เก็บใน `data/settings.json` ในเครื่องเท่านั้น ไม่ส่งไปหน้าเว็บ และไม่ขึ้น GitHub
4. **อัปโหลดครั้งแรก:** ติ๊ก "ซิงก์ข้อมูลกับ Supabase อัตโนมัติ" → "ทดสอบการเชื่อมต่อ" → "อัปโหลดข้อมูลทั้งหมด (ครั้งแรก)"
   - ถ้ามีคนแก้บนเว็บไว้แล้ว ระบบดึงมาก่อน จึงไม่ทับของเว็บ
5. **ใช้งานประจำ:** ปุ่ม "ซิงก์ตอนนี้" ส่งของที่รอและรับการแก้ไขจากเว็บทันที

## สถานะแปลง: ระบบกลางตรวจ แล้วส่งให้ระบบสำรวจ

เครื่องสำนักงาน (ระบบกลางที่เชื่อมกับ LTAX) ตรวจทุกแปลงทุกครั้งที่ข้อมูลเปลี่ยน รวมถึงตอนนำเข้า .shp / Excel, หลังงาน LTAX และเมื่อมีการแก้จากเว็บ
แล้วเก็บผลรายแปลงในตาราง `llan_parcel_status` ของ Supabase ให้ระบบสำรวจ (หน้าเว็บ) ใช้เป็นรายการงาน
- **ข้อมูลตรง:** รูปแปลงตรงกับทะเบียน เชื่อมกับ LTAX ได้ และไม่มีเรื่องต้องแก้
- **ต้องปรับแก้ (สำรวจ):**
  - มีรูปแต่ไม่มีทะเบียน / มีทะเบียนแต่ไม่มีรูป / รหัสซ้ำ / รูปไม่มีรหัส
  - เนื้อที่เอกสารต่างจากแผนที่เกินค่าที่ตั้งไว้
  - การใช้ประโยชน์ / เจ้าของไม่ครบ
  - อาคารอยู่นอกแปลง / อาคารไม่มีรูป / รูปอาคารไม่มีทะเบียน
  - ข้อผิดพลาดที่ทำให้ส่ง LTAX ไม่ได้
- **รอดำเนินการใน LTAX:** ข้อมูลสำรวจครบแล้ว เหลือส่งเพิ่ม/แก้ใน LTAX หรือตรวจกับ LTAX แล้วไม่พบ (ทำที่เครื่องสำนักงาน)
- ดูได้ที่แท็บ "สถานะแปลง" (การ์ดสรุป ตัวกรอง รายการพร้อมสิ่งที่ต้องทำ คลิกเพื่อไปที่แปลง) และสีแผนที่ "สถานะแปลง (ระบบกลาง)"
- หลังนำเข้า .shp หรือ Excel หน้าจอจะแสดง "สรุปการเชื่อมข้อมูล" ทันที
- ปุ่ม "ส่งสถานะขึ้น Supabase" ในแท็บสถานะแปลง ใช้ส่งใหม่ทั้งหมด (ปกติส่งเองภายในไม่กี่วินาที)

## รอบงาน: ดึงจาก LTAX → สำรวจบนเว็บ → ส่งกลับรอลง LTAX

1. **ดึงข้อมูลจาก LTAX มาที่ L-LAN (เครื่องสำนักงาน):** นำเข้า Excel ที่ส่งออกจาก LTAX หรือใช้งาน "ดึงข้อมูลจาก LTAX มาที่ L-LAN" ในแท็บส่งเข้า LTAX
2. **ซิงก์ลง L-LAN Web:** ถ้าติ๊กซิงก์อัตโนมัติไว้ ข้อมูลขึ้น Supabase เองภายในไม่กี่วินาที (หรือกด "ซิงก์ตอนนี้")
3. **สำรวจบนเว็บ:** แก้ข้อมูล วาด/แก้รูป ถ่ายรูป และบันทึกสถานะการสำรวจของแต่ละแปลง (ในแผงข้อมูลแปลงบนแผนที่ หรือแท็บสถานะแปลง)
   - **กำลังสำรวจ:** ยังทำไม่เสร็จ
   - **ต้องกลับไปซ้ำ:** ใส่เหตุผล เช่น เจ้าของไม่อยู่
   - **✓ สำรวจเสร็จ:** ข้อมูลที่แก้ของแปลงนี้ (ที่ดิน อาคารในแปลง และเจ้าของ) ไปรอให้สำนักงานลง LTAX
     คำเตือนเรื่องเนื้อที่ การใช้ประโยชน์ และเจ้าของ ถือว่าผู้สำรวจตรวจแล้ว ส่วนข้อผิดพลาดยังต้องแก้ก่อน
   - ถ้าแก้ข้อมูลแปลงนั้นอีกหลังกดสำรวจเสร็จ สถานะจะเป็น "แก้ไขหลังกดสำรวจเสร็จ" และหลุดจากรายการรอลง LTAX จนกว่าจะกดสำรวจเสร็จอีกครั้ง
4. **ส่งกลับรอลง LTAX:** เครื่องสำนักงานรับการแก้ไขจากเว็บทุก 1 นาที แปลงที่สำรวจเสร็จขึ้นที่
   - ตัวเลขบนแท็บ "ส่งเข้า LTAX" และรายการ "สำรวจเสร็จ รอลง LTAX" ในแท็บสรุปการแก้ไข
   - งาน LTAX เลือก "แปลงที่สำรวจเสร็จแล้ว (รอลง LTAX)" เป็นค่าเริ่มต้น (ทดลองก่อน แล้วค่อยบันทึกจริง)
   - ลง LTAX ครบแล้ว แปลงจะเป็น "สำรวจเสร็จ ตรงกับ LTAX แล้ว"

**การแสดงผลสำหรับงานสำรวจ:**
- สีแผนที่ "ความคืบหน้าการสำรวจ": ยังไม่สำรวจ (เทา), กำลังสำรวจ (ฟ้า), ต้องกลับไปซ้ำ (แดง เส้นประ), สำรวจเสร็จ (เขียว), แก้ไขหลังสำรวจเสร็จ (ส้ม) พร้อมแถบ "สำรวจแล้ว x / y แปลง (%)"
- แท็บสถานะแปลง: การ์ดความคืบหน้า และตัวกรองตามสถานะการสำรวจ
- แผงข้อมูลแปลง:
  - เจ้าของพร้อมเลขประจำตัวแบบปิดบางหลัก (1-1017x-xxxx-45-1) โทรศัพท์ (แตะเพื่อโทร) และที่อยู่
  - อาคารและป้ายในแปลง (แตะเพื่อไปที่อาคาร)
  - ปุ่ม "นำทาง" เปิดเส้นทางใน Google Maps
- **รูปถ่าย:** ถ่ายหรือเลือกรูปได้หลายรูปต่อแปลง/อาคาร (ในแผงข้อมูลบนแผนที่และในฟอร์มแก้ไข)
  - รูปถูกย่อให้ด้านยาวไม่เกิน 1600 px แล้วเก็บใน Supabase Storage (bucket `llan-photos` แบบส่วนตัว)
  - สมาชิกดูได้ editor/admin เพิ่ม/ลบได้ ถ้าเปิด GPS ไว้จะบันทึกพิกัดตอนถ่ายด้วย
  - ต้องรัน SQL ชุดล่าสุด (มีส่วนสร้าง bucket) ก่อนใช้รูป

## L-LAN Web (เปิดผ่านเว็บได้ทุกที่)

https://sutisukkawaguji-spec.github.io/L-LAND/ คือ L-LAN ตัวเต็มที่ทำงานบนข้อมูลใน Supabase ล็อกอินด้วยอีเมลและรหัสผ่านของ Supabase Auth
- ใช้ได้ทุกแท็บ ยกเว้น "ส่งเข้า LTAX", "ตั้งค่า" และการนำเข้าไฟล์ ซึ่งทำที่เครื่องสำนักงาน
- ส่งออก Excel / .shp ได้จากเว็บ (สร้างไฟล์ในเบราว์เซอร์)
- หน้าเว็บดึงการแก้ไขของคนอื่นทุก 30 วินาที (ไม่รบกวนฟอร์มที่เปิดแก้อยู่)
- `map.html` คือหน้าแผนที่อย่างเดียว (เบากว่า)
- เว็บ deploy อัตโนมัติด้วย GitHub Actions (`.github/workflows/pages.yml`) ทุกครั้งที่ push ขึ้น main
  - ค่า Supabase ในเว็บมาจาก `web/config.js` ซึ่งเก็บเฉพาะ **publishable key** สคริปต์ build ปฏิเสธ secret key

**ทดลองในเครื่อง:**
1. คัดลอก `web/config.example.js` เป็น `web/config.js` แล้วใส่ publishable key
2. รัน `node scripts/build-web.mjs`
3. เปิดโฟลเดอร์ `dist-web` ผ่านเว็บเซิร์ฟเวอร์ใดก็ได้ ที่ไม่ใช่ 127.0.0.1 / localhost (สองชื่อนี้คือโหมดเครื่องสำนักงาน)

## ใช้งานหลายอุปกรณ์

หน้าจอปรับตามขนาดเครื่อง:
- **คอมพิวเตอร์:** แผงข้อมูลอยู่ด้านขวา
- **แท็บเล็ตและมือถือ:**
  - แผงข้อมูลเลื่อนขึ้นจากด้านล่าง
  - ฟอร์มแก้ไขแสดงเต็มจอ
  - ซูมด้วยสองนิ้ว และปุ่มมีขนาดใหญ่ขึ้นสำหรับนิ้ว

ค่าเริ่มต้นของเซิร์ฟเวอร์รับเฉพาะเครื่องที่รันอยู่ (127.0.0.1)

ถ้าจะให้แท็บเล็ตหรือมือถือในวง LAN เปิดได้ ให้ตั้ง `LLAN_HOST=0.0.0.0` แล้วเปิด `http://<IP เครื่องนี้>:4380` แต่มีข้อจำกัด 2 อย่าง:
- **ไม่มีการล็อกอินฝั่งเซิร์ฟเวอร์:** ทุกเครื่องในวงเดียวกันเปิดดูข้อมูลได้
- **GPS ใช้ไม่ได้:** เบราว์เซอร์มือถือเปิดให้ใช้ GPS เฉพาะหน้าเว็บที่เป็น https เท่านั้น

## ขอบเขตการส่งเข้า LTAX รอบแรก

**ทำได้:**
- เจ้าของ: เพิ่มใหม่และแก้ไข
- ที่ดิน: แก้ไข และเพิ่มใหม่จากหน้าเจ้าของเพื่อให้ LTAX ผูกเจ้าของเอง
- การใช้ประโยชน์ที่ดิน: แก้แถวเดิมและเพิ่มแถวใหม่
- สิ่งปลูกสร้าง: แก้ไข พร้อมแก้และเพิ่มการใช้ประโยชน์

**ยังไม่ทำ (ระบบจะแจ้งในคอลัมน์ "ต้องทำเอง"):**
- ลบแถวการใช้ประโยชน์
- เปลี่ยนเจ้าของของแปลงหรืออาคาร (ใน LTAX ทำผ่านหน้าต่าง popup)
- เพิ่มสิ่งปลูกสร้างใหม่ (ต้องเลือกแปลงใน popup)
- ป้าย

**ข้อควรระวัง:** โหมดบันทึกจริงทดสอบกับ LTAX จำลอง (`mock-ltax`) ที่ใช้ชื่อช่องและขั้นตอนเดียวกับระบบจริงเท่านั้น ยังไม่เคยกดบันทึกในระบบจริง ควรทดลองกับ 1 รายการที่ตรวจได้ก่อน

## ทดสอบ

    node --test "tests/*.test.mjs"

- **shapefile / xlsx / cp874:** อ่านและเขียนไฟล์
- **core:** กฎตรวจข้อมูล การนำเข้า Excel ของ LTAX การนำเข้าซ้ำโดยไม่ทับค่าที่แก้ และระบบพิกัด
- **engine:** ส่งและดึงข้อมูลผ่าน Chrome แบบไม่มีหน้าต่าง กับ LTAX จำลองเท่านั้น ไม่แตะระบบจริง

ดูหน้าตา LTAX จำลองเองได้ด้วย `node mock-ltax/server.mjs` แล้วเปิด http://127.0.0.1:4390/sso/login.do

## โครงสร้าง

- `server.mjs`: เซิร์ฟเวอร์ในเครื่องและ API
- `lib/`
  - `store.mjs`: ที่เก็บข้อมูล JSON และประวัติ `changes.jsonl`
  - `shapefile.mjs` / `cp874.mjs`: อ่านและเขียน .shp
  - `xlsx.mjs` / `export-xlsx.mjs`: อ่านและเขียน Excel
  - `import-ltax.mjs`: นำเข้า Excel ของ LTAX
  - `layers.mjs`: นำเข้าแผนที่ จอย ซ้อนทับ และส่งออก .shp
  - `cdp.mjs` / `ltax-driver.mjs` / `ltax-engine.mjs`: ควบคุม Chrome และกรอกข้อมูล LTAX
- `public/`: หน้าเว็บ
- `public/shared/`: ใช้ร่วมกันทั้งหน้าเว็บและเซิร์ฟเวอร์ ได้แก่ รหัสและช่องของ LTAX, กฎตรวจ, การคำนวณ, ระบบพิกัด, การเทียบความต่าง
- `mock-ltax/`: LTAX จำลองสำหรับทดสอบ
- `docs/ltax-online-map.md`: ผังระบบ LTAX ONLINE ที่สำรวจจากระบบจริง
