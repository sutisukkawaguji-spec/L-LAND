# ผังระบบ LTAX ONLINE (สำรวจ 9 พ.ย. 2569)

สำรวจจากบัญชีจ้างเหมา (จัดเก็บ) ของ อบต.น้ำโสม จ.อุดรธานี (รหัส อปท. 06411806) แบบอ่านอย่างเดียว
ไม่มีการบันทึก ลบ ยกเลิก หรือส่งออกรายงานในระบบจริง เอกสารนี้ไม่มีข้อมูลส่วนบุคคล

## ทางเข้า

- เข้าสู่ระบบที่ `https://lsso.dla.go.th` (DLA Single Sign-on): ชื่อผู้ใช้ + รหัสผ่าน แล้ว OTP ทางอีเมล หรือ ThaiD
- ระบบที่บัญชีนี้ใช้ได้: SSO (จัดการผู้ใช้), LPA (ระบบประเมิน), **LTAX ONLINE**, INFO (ข้อมูลกลาง อปท.), LSV (บริการประชาชน)
- LTAX ONLINE: `https://ltax.dla.go.th` เป็นเว็บ JSP + Struts (`*.do`) แบบ server-render ทุกหน้าใช้ฟอร์มเดียว POST กลับ URL เดิม
  พร้อม `cmd=<คำสั่ง>` และ `data_index=<ลำดับแถว>` (ฟังก์ชัน `doCmd(cmd, index)`)
- ปีภาษี: ทะเบียนทรัพย์สินอยู่ปี 2570, การจัดเก็บรายได้และคำร้องอยู่ปี 2569 (เปลี่ยนที่ UMS009 `assetYear` / `revYear`)

### ห้องชุด (AST002) — ยังไม่ได้ลงรายละเอียด

ค้นหาด้วยชื่ออาคารชุด ห้องชุดผูกกับเจ้าของ: ชื่ออาคารชุด, ห้องเลขที่, ชั้น, พื้นที่รวม (ตร.ม.)

## ขั้นตอนการทำงาน

```
ทะเบียนทรัพย์สิน (AST001: เจ้าของ → ที่ดิน + การใช้ประโยชน์ → สิ่งปลูกสร้าง + การใช้ประโยชน์ → ป้าย)
  → ภ.ด.ส.1/2 ประกาศราคาประเมิน → ภ.ด.ส.3/4 บัญชีรายการแจ้งเจ้าของ (ส่งเอง หรือไฟล์ไปรษณีย์ไทย)
  → REV001 ประเมินภาษี (สร้างจากหน้าเจ้าของ: taxAssessment.do?cmd=goCreate&ownerId=…) = ภ.ด.ส.6/7/8
  → REV012 หนังสือแจ้งเตือน (ถ้ายังไม่ชำระ)
  → REV002 รับชำระ (ใบเสร็จ RCPTP-xxxxx/ปี; รายการ BATCH มาจากช่องทางออนไลน์/e-LAAS)
  → คำร้อง PET001–PET010 แก้ไข/คัดค้าน/ผ่อน/คืนเงิน
ป้าย: AST001 ป้าย → REV004 ยื่นแบบ/ประเมิน → REV005 รับชำระ → PET010 อุทธรณ์
```

ข้อมูลการประเมิน (REV001) ต่อราย: เลขที่เอกสาร (`n/ปี`), วันที่ประเมิน, ค่าภาษี, ยอดยกเว้น, ภาษีหลังยกเว้น, ยอดลดหย่อน, คงเหลือ
และตารางรายการ: ประเภท (ที่ดิน / ที่ดิน+สิ่งปลูกสร้าง), การใช้ประโยชน์, ตร.วา, ประเภทสิ่งปลูกสร้าง, ตร.ม., ราคา, ส่วนที่ได้รับยกเว้น, ฐานภาษี

ข้อมูลการรับชำระ (REV002): เล่มที่, เลขที่ใบเสร็จ, วันที่รับชำระ, ผู้ชำระ, ค่าภาษี, เบี้ยปรับ % และจำนวนเงิน, เงินเพิ่ม (เดือน, บาท), ยอดชำระ

- รายงานใหญ่เข้า "คิวออกรายงาน" (MAS023) แล้วค่อยดาวน์โหลด

## คำสั่งที่เปลี่ยนข้อมูลในระบบจริง (ห้ามเรียกจากเครื่องมืออัตโนมัติ)

`doSave`, `doSaveOwner`, `doDelete`, `doDeleteFile`, `doUpdateAsset`, `checkSave()`, `checkCancel()` (ยกเลิกการประเมิน/การรับชำระ), `doSetYear`, `agree`, `doBatchPostal()`

## ฟอร์มแก้ไข (เปิดดูเมื่อ 9 พ.ย. 2569 โดยไม่บันทึก)

- `goUpdate` ของเจ้าของจะเปิดหน้าสรุปเจ้าของก่อน ในหน้านั้นมี:
  - "แก้ไขข้อมูล" (`doUpdateOwner`)
  - "เพิ่มที่ดิน/สิ่งปลูกสร้าง/ป้ายใหม่" (`doAddNewAsset`, 'land'|'building'|'signboard') ซึ่งจะผูกเจ้าของให้อัตโนมัติ
  - "เพิ่มที่มีอยู่ในระบบ" (`popupCmd('listLandPage'|'listBuildingPage'|'listSignboardPage'|'listCondoRoomPage')`)
- ฟอร์มที่ดินมี `land.id` (hidden) และ `ORG_ID`
  - การใช้ประโยชน์แต่ละแถว: แก้ด้วย `doUpdateLandUsed(i)`, ลบด้วย `doDeleteLandUsed(i)`
  - เจ้าของ: `doUpdateOwnerFromAsset(i)`, `doDeleteOwnerPage(i)`
  - `goAddLandUsed` จะไม่เปิดหน้าใหม่ถ้าใช้ประโยชน์เต็มพื้นที่แล้ว โดยแจ้ง "ใช้ประโยชน์เต็มพื้นที่แล้ว" ใต้ footer
- หน้าการใช้ประโยชน์ที่ดิน:
  - ช่อง: `landUsed.id`, `landUsed.remainWah` (hidden), `landUsed.usedType`, `landUsed.raiStr`, `nganStr`, `squareWahStr`, `landUsed.usedFor`, `landUsed.usedBy`, `landUsed.agriType`, `landUsed.note` และรูปภาพ
  - ปุ่ม "ตกลง" = `if(validateForm(this.form)) checkArea();`
  - ปุ่ม "กลับไป" = `doCmd('goBackLandForm')`
- รหัส `landUsed.usedType`:
  - 1 = 1-เกษตรกรรม
  - 2 = 2-(1)ที่อยู่อาศัย หลังหลักและหลังอื่นบนพื้นที่เดียวกัน
  - 3 = 2-(2)หลังหลัก กรณีไม่ใช่เจ้าของที่ดิน
  - 4 = 2-(3)หลังอื่นๆ
  - 5 = 3-อื่นๆ
  - 6 = 4-ทิ้งไว้ว่างเปล่า
  - 8 = 4-ว่างเปล่า ตั้งแต่ 3 ปี
  - 9 = 4-ว่างเปล่า ตั้งแต่ 6 ปี
  - 7 = 5-ใช้ประโยชน์หลายประเภท
- รหัสอื่นของที่ดิน:
  - `usedFor`: 1 ใช้เอง, 2 ให้เช่า, 3 ให้บุคคลอื่นทำประโยชน์
  - `agriType`: 1–13 (ปลูกข้าว ... เลี้ยงสัตว์อื่นๆ)
  - `land.docType`: 1–13 ตามลำดับในรายการ
  - `land.utm2`: 1–4 = I–IV
- ฟอร์มสิ่งปลูกสร้าง:
  - ช่องเพิ่มเติม: `building.taxYear`, `building.id`
  - `building.landList[0].landUsedId` = เลือกแถวการใช้ประโยชน์ของแปลงที่ตั้ง
  - `building.buildingType` ใช้ค่ารหัส เช่น `106` หรือ `506/1` (รายการเต็ม 101–614)
  - `building.structure`: 1 ไม้, 2 ตึก, 3 ครึ่งตึกครึ่งไม้
- หน้าการใช้ประโยชน์ในสิ่งปลูกสร้าง:
  - ช่อง: `buildingUsed.usedType` (ตัวเลือกถูกจำกัดตามการใช้ประโยชน์ของแปลง), `fullArea` (checkbox), `buildingUsed.useFloor`, `widthStr`, `lengthStr`, `areaStr`, `buildingUsed.usedFor` (1 ใช้ประโยชน์เอง, 2 ให้เช่า), `note`
  - ปุ่ม "ตกลง" = `doSaveBuildingUsed`
  - ปุ่ม "กลับไป" = `goBackBuildingForm`
- `doCmd` (ซอร์สจริง):
  - `doSave*` → `validateForm` แล้วถ้ามี `notCurrentYear` จะขึ้น SweetAlert "ยืนยันการแก้ไขข้อมูลปีภาษี …"
  - `doDelete*` → SweetAlert "ยืนยันการลบข้อมูล"
- รายการคำนำหน้าชื่อมีมากกว่า 40 รายการที่เก็บมา เช่น พระ, พ.ต.ท.

## ยังไม่ได้สำรวจ
- ตารางราคาประเมินสิ่งปลูกสร้าง MAS003 และอัตราภาษีป้าย MAS004 ทั้งหมด
- ฟอร์มสร้างการประเมิน (REV001 goCreate), ฟอร์มรับชำระ, ฟอร์มคำร้องแต่ละแบบ
- popup เลือกเจ้าของ/เลือกแปลง, การดึงข้อมูลกรมที่ดิน, DBD, กรมธนารักษ์
- ห้องชุด, แผนที่ omap, หน้ารายงานภาพรวม
